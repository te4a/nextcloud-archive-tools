# 7-Zip 26.06

7-Zip is by Igor Pavlov and is available at <https://www.7-zip.org/>.
The bundled binaries are the unmodified static `7zzs` programs from the official
[7-Zip 26.06 Linux x64 and arm64 archives](https://github.com/ip7z/7zip/releases/tag/26.06).
Archive Tools invokes them as separate programs. 7-Zip is mainly licensed under
the GNU LGPL. The included `License.txt`, `copying.txt` and `unRarLicense.txt`
cover the license terms and notices for this distribution.

The complete corresponding upstream source is included as `7z2606-src.tar.xz`.
Its `DOC` directory contains the upstream build instructions and source notices.
